# Movie Hub

Aplicativo mobile para busca de filmes

## Funcionalidades

-Pesquisar filmes
-Adicionar filmes
-Ver informações sobre todos os filmes adicionados
-Remover filmes
-Favoritar filmes
-Compartilhar filmes


## Tecnologias utilizadas

-React Native
-TypeScript
-Expo

## Estrutura do projeto

-assets
nesta pasta temos somente a pasta images
-images
nesta pasta temos todas imagens utilizadas no projeto
